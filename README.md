# Marinho RP - Android prototype 0.3

Primeiro protótipo 3D de exploração para Godot 4.

## O que já existe nesta base
- Cena 3D inicial com chão, iluminação e prédios de bloco.
- Personagem controlável em terceira pessoa.
- Joystick virtual básico para tela touch.
- Projeto configurado para renderização Compatibility, adequada para começar testes em celulares Android.

## Abrir
1. Instale o Godot 4 em um computador.
2. Extraia esta pasta.
3. No Godot, escolha Importar e selecione `project.godot`.
4. Execute a cena principal.

## Importante
Esta é uma base inicial de protótipo, não um jogo final. Ainda não inclui APK, veículos, interiores, missões, conta/login, sincronização online ou servidor de 50 jogadores. O visual atual usa formas simples temporárias. Multiplayer e otimização Android precisam ser implementados e testados em etapas posteriores.
